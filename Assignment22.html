About CSS

CSS stands for Cascading Style Sheets. It is used to style HTML webpages with colors, spacing, fonts, and layouts.

Types of Selectors

  • Universal Selector (*)
  • Element Selector (body)
  • Class Selector (.card)
  • ID Selector (#main-heading)
  • Group Selector (h2, h3)
  • Descendant Selector (.card p)
  • Pseudo-class Selector (a:hover)

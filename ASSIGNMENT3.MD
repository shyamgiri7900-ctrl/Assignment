Q.3 Complete a short terminal-navigation practice sheet.


Ans. Here is a short terminal-navigation practice sheet with commands and solutions.
Terminal Navigation Practice Sheet
No.	Task	Command / Answer
1	Show the current directory	pwd
2	List files and folders	ls
3	Create a new folder named Practice	mkdir Practice
4	Move into the Practice folder	cd Practice
5	Go back to the parent directory	cd ..
6	Create a file named hello.txt	touch hello.txt
7	Clear the terminal screen	clear
8	Go to the home directory	cd ~
9	Display the contents of a file	cat hello.txt
10	Remove an empty folder named Practice	rmdir Practice

Remember: cd changes directories, ls lists files, and pwd shows your current location.

Practice tip: Run each command in a terminal one by one. Note that touch is commonly available on Linux and macOS terminals; Windows Command Prompt uses different commands.

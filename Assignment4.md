Q.4 Submit a repository with at least three meaningful commits.
Ans. Step 1: GitHub repository banao
1. GitHub par New Repository kholo.
2. Repository name rakho: web-development-practice
3. Public select karo.
4. Create repository par click karo.
Step 2: VS Code mein project banao
Ek folder banao aur usmein ye 3 files rakho:
- index.html — webpage ka structure
- style.css — webpage ki styling
- README.md — project ki information
Step 3: 3 meaningful commits karo
VS Code ke terminal mein ye commands ek-ek karke run karo:

Commit 1 — Initial project setup
git init
git add README.md
git commit -m "Initial project setup"


Commit 2 — Add webpage structure

Pehle index.html file banao, phir:
git add index.html
git commit -m "Add homepage structure"


Commit 3 — Add styling

Pehle style.css file banao, phir:
git add style.css
git commit -m "Add homepage styling"
